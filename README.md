## The memory

> The dial-up tone still lives in my head rent-free — that screech meant the internet was coming, and for one glorious hour the whole world fit inside a humming beige box.

One sentence, 169 characters — the sound of a modem connecting, and the whole world arriving through a humming beige box.

## Run it

```sh
python3 main.py
```

That prints the memory above. To print its character count instead:

```sh
python3 main.py --chars

```
